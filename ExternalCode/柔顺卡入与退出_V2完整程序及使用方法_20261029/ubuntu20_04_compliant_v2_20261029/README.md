# 柔顺卡入与退出 V2

版本 compliant-v2-20261029。完整 Python 源码，运行目录 ubuntu20_04_compliant_v2_20261029。

本版采用位置小步运动加力反馈约束，实现有界横向减载搜索。它不是控制器原生连续力控，尚未在真机完成标定和验收。

先读同目录 使用方法.txt。工具仍卡在工件上时，只运行 probe，并由现场人员解除约束；不要用新程序强行拉出。

相较前版，卡入和退出都采用实际位移检查；卡入速度上限 0.4 mm/s、步长上限 0.10 mm；退出速度上限 0.6 mm/s、步长上限 0.15 mm。载荷升高时连续降速，有载步长上限 0.05 mm。

搜索继续条件为每轮确实改善载荷，并且没有明显增加轴向力或力矩；最多八轮、实际横向偏移不超过 0.30 mm。不再固定两轮结束后即放弃仍有效的改善，但保持约 7.8 的清除判据，未达到时不会继续轴向移动。

受力异常和进程中断会留下 contact_session.json，后续运动被阻止。现场确认解除接触且只读检查通过后，可用文档中的复位命令清除。probe 和计划检查不会清除该记录。

原 30 N 合力、力矩、反馈超时等硬限值保持生效。卡入提前停止轴向力默认 12 N，退出默认 18 N；这些是保守的试用起点，并非已经验证的工艺最优参数。

自动周期需要先显式设置已经验证的 CR10AF_DISTANCE_MM；只拧紧入口保持可用。

源码依赖和反馈布局参考 [Dobot 官方 SDK](https://github.com/Dobot-Arm/TCP-IP-Python-V4/blob/main/dobot_api.py)。
