# SoftWare 1.12 测试更新：半自动流程、轨迹采样与运行历史

版本标签：`v1.12-test.20261028`。这是待现场验收的测试版，不是整机实物全流程验收通过的正式版。

## 本次更新

- 集成伍老师21.5.wlj的操作日志与项目运行历史，支持按模式筛选、查看步骤及结果；未采集的数据明确标注，不以默认零值代替实测。
- 真实“开始运行”接入半自动流程：粗定位实际到位确认 → 等待人工确认并拧紧 → 接触/拧紧/退出 → 返程 → 下一目标重新确认。视觉算法尚未接入，实物阶段由人工确认跳过视觉。
- 离线全流程同步人工继续关卡，并保留小幅模拟视觉精调；模拟与真实设备权限隔离，模拟成功不等于实物到位。
- 粗定位与返程增加自适应关节路径采样，解决规划端点稀疏却触发相邻角差限制的问题。`maxJointStepDeg`通常保持5，不需要改成100；真实软限位、起点核对、反馈及停止保护保留。
- 机械臂段内连续排队下发，中间点CP50、末点CP0，不逐点等待停稳；仅段末核对命令ID、新鲜反馈、空闲状态及六轴误差。发送节流按原规划线段分摊，避免补点导致缓冲时间重复累加。
- 增加底盘新/旧模式开关：新模式查询任务状态；旧模式按时间估算后等待人工确认底盘位置、朝向和停稳。不自动从新模式降级到旧模式。
- 增加`trajectory-plan.json`，记录原始/采样角度、来源点及发送间隔；诊断标识更新为`sampled-trajectory-v2-2026-10-15`。

## 安装及使用

- Linux x86_64请下载本Release单独附加的运行包；GitHub自动生成的Source code压缩包是源码，不能直接当安装包运行。运行包只有完成构建并上传附件后才可下载。
- 解压并保留整个构建目录，包括可执行文件、`*_Data`、Unity依赖文件、`ExternalCode`及字体，不要只替换可执行文件或某一个Python脚本。
- 目标工控机仍需匹配的Python及依赖；Unity构建不会自动把系统Python环境打进去。视觉识别模型与SDK为额外依赖。
- 更新前关闭旧软件与旧Python服务，备份既有项目、`Data`目录和持久配置。新包不要用空数据库覆盖原有历史，也不要把本机私人数据库或现场配置上传到Release。
- 详细步骤见运行包中的`FIELD_COMMISSIONING.md`；延迟测试见`COMMUNICATION_LATENCY.md`。先核对实际软限位、起点、User/Tool，再在现场监护下进行单目标测试。
